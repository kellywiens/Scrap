# Starting a new Scrap project

1. Create a folder for the project inside the Scrap repository.
2. Add your scripts or other project files to that folder.
3. Open the folder or repository in VS Code and ask Copilot to help with the files.
4. In Source Control, stage the files you want to keep and create a commit.
5. Publish or push the branch to GitHub when you are ready.

To work on a separate branch, create one from an existing commit before making
your changes. A new repository needs its first commit before Git can create a
branch from `HEAD` or push that branch.
